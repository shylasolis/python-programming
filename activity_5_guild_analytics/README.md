# Activity 5: Guild Analytics

Over two sessions, analyze a guild-member spreadsheet with pandas, clean a messy version of the data, and create a chart from the results.

## Textbook Connection

This activity applies *Murach's Python for Data Science*, Section 1:

- Part A: load CSV data into pandas DataFrames, inspect columns, filter rows, add calculated columns, and summarize groups.
- Part B: identify missing values, inconsistent text, invalid data types, and duplicate rows before analyzing or plotting data.
- NumPy and matplotlib support numeric work and visualization.

The activity builds on the roster database from Activity 4. Instead of working with one character at a time, you will ask questions about an entire dataset.

## Get Started

1. Install the needed packages with `pip install pandas numpy matplotlib`.
2. Open `code/guild_analytics_starter.py`.
3. Run it with `python code/guild_analytics_starter.py`.
4. Complete TODOs 1-4 with `guild_members.csv`, then TODOs 5-8 with `messy_guild_members.csv`.
5. Use [student_guide.md](student_guide.md) for the activity instructions.
