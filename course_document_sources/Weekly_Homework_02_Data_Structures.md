## Purpose

In class, you built a trivia game that stores questions as structured data and processes them with functions and loops. This homework gives you individual practice with lists, dictionaries, functions, and input validation using the textbook's exercises.

## Read and complete: all three exercises are required

Use the exercise files that accompany your textbook, if provided. Follow the book's instructions for opening and running each program. The page numbers below are the printed page numbers in the 2nd edition.

### A. Required: Dictionaries - Exercise 12-2, pages 353-354

Complete steps 3-7 of "Enhance the Movie List 2D program." Convert each movie record to a dictionary while keeping the collection of movies as a list. Update the list, add, and delete behavior so the program still works.

This is the main assignment because it practices the same data shape used by the trivia question bank: a list containing dictionaries with named fields.

### B. Required: Lists and Functions - Exercise 6-1, pages 199-200

**Exercise 6-1 is required. Complete steps 3-6** of "Use a list for the Test Scores program." Store the scores in a list, pass that list between functions, and calculate the total, count, and average.

**Only step 7's additional statistics are optional enrichment.** This does not make Exercise 6-1 optional.

### C. Required: Exceptions - Exercise 8-1, page 251

Complete steps 3-4 of "Add exception handling to the Future Value program." Test invalid numeric entries, add exception handling, and test again. Pay attention to the difference between invalid text that cannot be converted to a number and a number that is outside the allowed range.

## Using AI for homework

AI is allowed as a learning and review tool. You are responsible for the submitted work and must be able to explain it.

Good requests include:

- "Explain what this traceback is telling me. Give me one hint, not a complete rewrite."
- "Review my function call and explain why the value is not being returned as expected."
- "What tests should I try for this input validation? Do not write the solution."

Do not ask AI to complete the textbook exercises for you or submit code you cannot explain. Verify any generated advice by running your program and checking the result. Disclose meaningful AI assistance in your **journal**.
