# Activity 1: Build-Your-Own Escape Room

Build a text-based escape room game in Python. You will guide a player through rooms, choices, and puzzles while practicing the control flow that makes a program respond to input.

## Textbook Connection

This activity applies concepts from *Murach's Python Programming*, Section 1 Part B:

- Operators and Boolean expressions decide whether a player can take an action.
- `if`, `elif`, and `else` create different outcomes for player choices.
- A `while` loop keeps the game running until the player escapes or quits.
- Lists and `for` loops help track and check the player's inventory.

The game is a concrete example of how variables, conditions, and loops work together in a complete program.

## Get Started

1. Open `code/escape_room_starter.py`.
2. Run it with `python code/escape_room_starter.py`.
3. Complete the `# TODO` comments in order.
4. Use [student_guide.md](student_guide.md) for the activity instructions.

Your goal is to understand and write the game logic yourself. AI can help explain errors or brainstorm story details, but you should be able to explain each loop and conditional in your finished game.
