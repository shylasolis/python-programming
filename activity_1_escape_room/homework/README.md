# Chapter 3 Homework Starter Programs

These original starter programs are provided for the Chapter 3 exercises associated with Activity 1: Escape Room. They provide a runnable starting point for the textbook's Exercises 3-1 through 3-3; they are not completed exercise solutions.

## Files

- `chapter_3_starters\mpg_exercise_starter.py` — single-trip Miles Per Gallon program; extend it for repeat trips and fuel cost.
- `chapter_3_starters\test_scores_exercise_starter.py` — one-set Test Scores program; extend it for repeated sets, the `end` sentinel, and an assignment expression.
- `chapter_3_starters\future_value_exercise_starter.py` — Future Value Calculator; extend it with input validation and yearly output.

Run a starter from the repository root, for example:

```powershell
python activity_1_escape_room/homework/chapter_3_starters/mpg_exercise_starter.py
```

Use these starter programs alongside the textbook directions and the submission instructions provided for the assignment.
