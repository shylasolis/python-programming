# Activity 2: AI-Generated Trivia Night

Build a console trivia game with a question bank, score tracking, and friendly handling of unexpected input.

## Textbook Connection

This activity applies concepts from *Murach's Python Programming*, Section 2 Parts A and B:

- Functions organize repeated work, such as asking and checking a question.
- Lists and dictionaries store a structured question bank.
- Tuples are useful for fixed values, such as multiple-choice options.
- `try` and `except` handle input problems without crashing the game.
- String methods make answer comparisons more reliable.
- The `datetime` module can timestamp a high score.

The activity moves from hardcoded decision branches to programs driven by organized data.

## Get Started

1. Open `code/trivia_starter.py`.
2. Run it with `python code/trivia_starter.py`.
3. Complete the `# TODO` comments in order.
4. Use [student_guide.md](student_guide.md) for the activity instructions.

Verify any AI-generated trivia facts before adding them to your game. You should write and understand the functions, data handling, and error handling.
