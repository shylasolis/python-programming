# Activity 6: Guild Election Polling Case Study

Over two sessions, analyze fictional guild-election polling data, calculate weighted averages, chart changes over time, and write a clear report about the findings.

## Textbook Connection

This activity applies the Polling Case Study in *Murach's Python for Data Science*:

- Part A focuses on loading and aggregating polling data.
- Part B focuses on parsing dates, analyzing trends, creating visualizations, and communicating results.
- Weighted averages show why polls with larger sample sizes should contribute more to the result.

The project combines skills from earlier activities: structured data, pandas DataFrames, grouping, calculations, plots, and clear communication for a non-technical reader.

## Get Started

1. Ensure the Activity 5 packages are installed: `pip install pandas numpy matplotlib`.
2. Open `code/polling_analysis_starter.py`.
3. Run it with `python code/polling_analysis_starter.py`.
4. Complete TODOs 1-4 during the aggregation session and TODOs 5-7 during the trends and reporting session.
5. Use [student_guide.md](student_guide.md) for the activity instructions.
