# Activity 3: RPG Character Forge

Over two sessions, build an RPG `Character` class and save a character so it can be loaded after the program closes.

## Textbook Connection

This activity applies the object-oriented programming and file I/O material in *Murach's Python Programming*, Section 3:

- A class is a blueprint for creating related objects.
- Attributes store each character's data, such as name, health, and level.
- Methods define behaviors, such as taking damage or leveling up.
- File I/O lets a program write data to a file and read it back later.
- `try` and `except FileNotFoundError` handle the first run, when no save file exists yet.

The project shows why objects are useful: a character keeps its data and behaviors together, then file I/O preserves that data between program runs.

## Get Started

1. Open `code/character_forge_starter.py`.
2. Run it with `python code/character_forge_starter.py`.
3. Complete TODOs 1-4 during the class session and TODOs 5-6 during the file I/O session.
